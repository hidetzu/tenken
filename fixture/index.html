tenken fixture site

This site exists so that tenken (an external link, not expected to be broken) can be run against a site whose problems are known in advance. Every problem on it is deliberate, and the expected findings are in fixture/check.sh.

  • a page that is fine
  • a link to a page that does not exist (links.broken, 404)
  • a page robots.txt disallows (not fetched, counted)
  • an external link (fetched once; check.sh asserts only that it is not reported broken)
  • a link to a loopback address (not fetched, not_fetched.private)
  • a fragment (not a reference)
